# HireMeKit

Everything you need to get hired. $9.99 once.

## What it does

- Tailor your resume to any job description (ATS + Fancy PDF + DOCX)
- Generate cover letters, email signatures, LinkedIn rewrites
- Build a portfolio site (Studio tier)
- Skills assessment with learning roadmaps

## Pricing

- Free: 1 resume score, no PDF
- Pro: $9.99 lifetime — all resume + cover letter + signature + LinkedIn
- Studio: $39 lifetime or $9/mo — Pro + portfolio site + business card + logo

## Stack

- Frontend: Astro (static)
- API: Astro endpoints (Node)
- AI: MiniMax API
- Payments: Stripe
- DB: Supabase free tier
- Hosting: Vercel free tier

## Compliance

This project follows:

- SOC2 Type II controls (security, availability, confidentiality)
- ISO/IEC 27001:2022 (ISMS)
- OWASP Top 10 (2021)
- GDPR data-minimization principles
- PCI-DSS SAQ-A (Stripe Checkout only — no card data ever touches our servers)
